# Func Pipes 3

A minimal Flask and Vue starting point for a Python-oriented graph application.

## Run

```bash
cd /workspaces/clam/func-pipes-3
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000/ in a browser.

The project currently contains only the Flask index route, a Vue-powered page shell, a locally served Vue vendor build, and dark-mode styling. Graph representation and execution will be added separately.
